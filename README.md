- **Stat cards** (stats / streak / trophy) run on free shared servers and can occasionally rate-limit under heavy traffic — if one ever shows an error, it almost always recovers within minutes. For guaranteed uptime, use each project's one-click "Deploy to Vercel" button to self-host.
- Change every `theme=tokyonight` to `radical`, `dracula`, `merko`, or `gruvbox` to restyle everything at once.
- Update the repo names in **Featured Projects** any time to swap in a different pinned project.
